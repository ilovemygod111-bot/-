# عناصر موشن جرافيك خام

فيديوهات MP4 بدقة 1920×1080 و30 إطار في الثانية، عناصر بيضاء وصفراء على خلفية سوداء.
ضعها فوق الفيديو واستخدم وضع الدمج **Screen** أو **Add** لتختفي الخلفية السوداء.

| الملف | الوصف | المدة |
|---|---|---|
| 00_all_elements.mp4 | كل العناصر متتالية (للمعاينة) | 18 ث |
| 01_ring_burst.mp4 | حلقات تتوسع من المركز | 3 ث |
| 02_line_sweep.mp4 | خطوط ترتسم ثم تختفي | 3 ث |
| 03_shape_pop.mp4 | مثلث ومربع ودائرة وسداسي | 3.5 ث |
| 04_dot_wave.mp4 | شبكة نقاط بموجة | 4 ث |
| 05_bar_wipe_transition.mp4 | انتقال بأشرطة مائلة تغطي الشاشة | 2 ث |
| 06_spark_burst.mp4 | انفجار خطوط شعاعية | 2.5 ث |

لإعادة التوليد أو التعديل: `python3 scripts/generate_motion.py motion`

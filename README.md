# دروس STEAM تفاعلية

- [`steam-nucleus-lesson/index.html`](steam-nucleus-lesson/index.html): مختبر النواة (العدد الذري والنظائر). درس العلوم للصف الثالث المتوسط، الفصل الدراسي الأول، فصل «تركيب الذرة»، الصفحات 159–162. يتضمن باني ذرة ثلاثي الأبعاد مع نمط واقع افتراضي (WebXR)، وألعاباً، واستراتيجيات تدريس، وتقويماً قبلياً وبنائياً وختامياً.

افتح الملف في المتصفح مباشرة. النموذج ثلاثي الأبعاد يحتاج اتصالاً بالإنترنت لتحميل مكتبة three.js.
- [`steam-nucleus-lesson/درس-النواة-STEAM.pptx`](steam-nucleus-lesson/): عرض بوربوينت من 8 شرائح لدرس النواة (مراجعة Wordwall، مقدمة، ومحطات STEAM، وتقويم ختامي بثلاثة مستويات). ملاحظات المعلّمة والإجابات في ملاحظات كل شريحة. المصدر: `build-deck.js` (pptxgenjs).
- `steam-nucleus-lesson/ورقة-استقصاء-نظائر-الكربون.pdf`: ورقة عمل استقصاء جاهزة للطباعة (A4، صفحتان للطالبة + صفحة مفتاح إجابة). المصدر: `worksheet.html`.
